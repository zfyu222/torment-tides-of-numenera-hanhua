# 术语审校返工修复：修复前后对照

日期：2026-10-21T17:36:56+0800

## 修复内容

1. 展示层裁剪：`compact_term_input` 把 `entries` / `related_entries` / 候选里的 `evidence_rows` 裁到本批 `records` 中确实附带原文的行号；条目的可引证据若一条都不可见则保留原样，避免无处可引。
2. 提示补强：只能引用本条目 `evidence_rows` 中且原文已随附的行；`source_excerpt` 必须逐字连续；`entry_reviews` 不得包含只读关联项；`checks` 固定为两元素数组。
3. 出处比对忽略空白与换行差异（引文文字仍须逐字一致，改写、拼接、省略号照旧拒绝）。
4. 提取阶段 API 提示禁止把分析过程写进正文（该项只影响以后的提取运行）。

## 对照方法

- 样本：6 个真实术语审校任务包，其中 3 个在修复前首轮失败、3 个首轮通过；两个通道（项目 acy7 中转站、DeepSeek 官方）各跑一遍，共 12 次请求。
- 修复后输入由生产的 `render_protocol_input` 现渲染，判定仍走 `canonical_api_result` + `submit_in_transaction` 的完整验收链路，质量门槛未放宽。
- 未写入项目数据库、未占用任务或尝试次数、未改动正式译稿。
