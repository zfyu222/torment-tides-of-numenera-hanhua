# 术语提取 API 失败与 Token 消耗排查

2026-10-21。范围：当前游戏已有 API 请求、服务端 usage、原始回复、拒收记录和本地输入包。只读分析；未新增 API 请求，未改通用程序。用户要求后续停止使用 Sol，改回 API；当前暂停以避免原因未处理前继续消耗。

## 用量口径

- 两次正式执行累计 1,799 次请求尝试，1,231 次接收、568 次失败。另 82 条 cancelled 是未实际发出的预约，不计请求尝试。
- 已报告累计 30,808,420 Token：输入 13,802,671，输出 17,005,749。另 85 次实际请求没有可用 usage，不填零。
- 首次执行 8,010,797 Token；第二次执行 22,797,623 Token。用户后台的 23.11M 接近第二次执行，但缺少其时间范围和统计口径，不能认定完全对应。
- 输出中包含 9,889,131 推理 Token；它是输出的子项，不能再加一遍。缓存输入 2,226,031 也是输入子项，不能再相加。
- 接收请求消耗 20,416,546；失败请求已报告消耗 10,391,874，占已报告累计约 33.7%。成功接收仅表示提取协议/出处验收通过，尚未完成术语语义审校。

## 主要原因

1. **关闭思考没有落实到发出的参数。** 项目 `think_switch=false`，但平台名为 `custom_platform_shh`、地址为转发域名；当前 AINiee 参数适配只对 deepseek 平台名或官方域名发 `thinking.type=disabled`。因此当前设置没有显式关闭思考。第二次执行接口报告推理 9,889,131 Token，占该次总量约 43.4%。这说明服务实际生成了大量推理，不能以设置中的 false 认定已经关闭。
2. **推理挤占输出上限。** 189 次 `empty_response` 全部 `finish_reason=length`；每次 completion 为 16,384，且都报告为 reasoning。累计输入 1,644,927、输出/推理 3,096,543，总计 4,741,470，没有得到可收集的正文。另 130 次 `invalid_model_result` 也以 length 结束。直接提高输出上限可能继续增加消耗，不能作为首选修复。
3. **结果错误引发整批重试。** 298 次拒收中，135 次为术语不在所引原文中，8 次缺有效批内出处，11 次 non_translate 的 source 无效，139 次 JSON 解析失败，3 次缺少 non_translate，2 次缺 analysis。例：源文为 `White. Death.`，模型生成 `White Death`，不能据此伪造连续原文命中。上述确有出处问题；不能关闭校验或自动放行。当前提取按整批接收，少数条目错误也会导致重发整批。
4. **输入包元数据重复。** 固定步长抽样 100 个原始批次、5,500 条记录，本地 o200k 估算完整输入 807,835 Token、原文单独 169,997、metadata 单独 490,796。约 60.8% 是逐条重复的 group、资源路径、场景、类型和说明；原文约 21.0%。组件单独编码不严格可加，且这些数是本地估算，不是账单。必要出处应保留，但可以在后续新输入包中共用表/短引用，不必每条重复长路径和同一句提醒。
5. **服务故障叠加。** 51 次连接错误、14 次超时、14 次 502、2 次 400。已保存的 400 错误包含该账号分组和模型没有可用转发通道。这与模型 JSON/出处错误是不同原因，不能全部当超时重试。

提取跨批还会重复遇到同一人名/术语；当前接收产物中人物候选 6,516 条、原词去重 1,455，术语候选 13,088 条、原词去重 4,177。跨批语境仍需保留，后续统一审校会归并；不建议为省 Token 直接跳过已见名称，避免漏掉多义和候选差异。

## 后续执行约束

- 按用户最新要求不再派 Sol，保留已验收的 41 个修复批次；当前共完成 1,272/1,285 批。13 批未验收，其中 2 批有中断时遗留文件，不能把它们计为通过。
- 先使现有服务/模型明确收到关闭思考参数，再以少量真实失败批次核对 usage、截断、JSON 和出处；未证明修复前不直接启动大阶段。
- 输入瘦身应由程序恢复重复元数据，保留原文、ordinal、真实上下文与出处校验；不删语义证据、不降低验收门槛。已有在途输入不悄悄改写。
- 只接续未完成批次，保留原始请求、尝试次数和成功结果；不用全文重跑解决格式错误。
- 阶段推进仍为提取完成、术语审校与冻结、150 条随机试译、正文翻译与独立审校。现有正式 CSV 和游戏资源尚未覆盖。
